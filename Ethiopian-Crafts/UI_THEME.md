# Reusable UI theme brief

Use this brief when extending the Ethiopian Crafts storefront or starting a related project:

> Create a polished, edgy, warm, responsive interface with an ivory page background, warm white surfaces, ink-dark typography, generous spacing, softly rounded cards, light sand borders, and restrained warm shadows. Use deep espresso-to-terracotta gradients for prominent navigation and hero areas, with muted saffron highlights. Keep content uncluttered, readable, and accessible with strong contrast and visible keyboard focus states.
>
> Let the Ethiopian product artwork and artisan storytelling remain central. Balance dark modern surfaces with earthy terracotta, toasted gold, and natural cream; keep colors grounded rather than overly saturated. Preserve the existing shopping behavior and page structure; avoid unrelated redesigns.

## Design tokens

```css
:root {
  --bg-base: #f6efe6;
  --bg-surface: #fffdf9;
  --bg-card: #fffaf3;
  --accent-primary: #c96b4c;
  --accent-success: #286047;
  --accent-warning: #80500c;
  --text-normal: #241914;
  --text-muted: #6d5d52;
  --border-glow: #e7d8c8;
  --navy: #694334;
}
```

For hero areas and navigation, use gradients based on `#211713`, `#542719`, and `#a34324`. Use 12–22px rounded corners and soft warm shadows; reserve saffron for small craft-inspired details.
